# View Composition

视图组合定义 NewP 通过视图配置将页面组织为导航内容、树的节点内容和标签页组的公共语言。组合拥有页面的安排与上下文交接，页面所属模块拥有业务含义。

常规主外键树可使用平台 `platform.relations` Provider 与配置驱动 API，`relationSource` 声明同模块资源、模型字段、父关系及静态过滤；特殊业务仍注册自定义 Provider。标准读取复用资源权限及查询约束，消费冻结 authoring，不从前端接收表列映射。配置、适用范围和回退方式见 [ADR-0047](../../adr/0047-standard-relation-trees-use-configured-providers.md) 与 [接入指南](../../developer/relation-tree-configuration.md)。

导航 metadata 的 `routeOnly` 项声明不生成菜单的受控地址，`redirectTo` 兼容项只跳转，不装载另一套列表。完整详情可通过 `entryType: standard-crud-detail` 与目标 binding 显式声明，独立于列表菜单和兼容地址。导航根页面拥有标题与 `tab` 地址状态，并通过显式导航桥交接直属树的 `node` 与节点标签 `nodeTab`；URL 只描述当前活动标签的树，各兄弟标签的位置保留在所属 Tab 实例，切换时原子交接该标签与其定位参数；其他内嵌页面保持局部选择、筛选和分页。恢复时重新读取目标当前路径及必要祖先的直属集合，不持久化其他会话展开状态；缺失节点提示“目标节点已不存在”后才回退首个有序根，读取失败保留定位输入并提供只读重试。异步定位完成时再次检查当前组合的未保存／提交状态，确认前不替换旧节点内容。PageProps 的 `active` 表示整个父链是否可见，隐藏页面仍报告未保存／提交状态，但应隐藏 Portal 呈现；同一配置的实例使用独立查询身份。

树搜索浮层只展示搜索时的名称、类型词典标题、编码与完整路径；选择结果重新定位，不直接消费旧路径。搜索按完整 Provider 范围分页，关键词或范围变化回到第一页；根、分支、搜索和定位请求各自取消过期响应，失败不冒充空集合。直属读取不分页，其返回规模和数据库成本由模块真实查询测量，不声明未经测量的容量保证。

标准 Mutation 与 Action Execution 将 Adapter 的 `ResourceChange` 成功事实交接一次；业务 presenter 只解释业务结果。Organization 用 `hasChangeSnapshot` 声明本次所需旧字段，不足时在写入前经既有详情入口补读；删除结果保留旧快照，不重读已删记录。`resolveChange` 在同一 Provider 范围内区分不相关、明确位置与待确认，缺少旧位置不是根位置。

外层组合等未保存／提交状态解除后协调读取，当前脏输入不被刷新覆盖。已打开但非活动的树按节点合并待处理影响并保留全部旧、新父分支，激活时只读恢复；同资源的非活动标准页面延迟刷新。树内创建选择新节点；目录操作不抢导航；移动保留选择并解析新路径；删除回退父节点、剩余根或空状态。Provider 正常返回未知映射时保守重读根、全部已加载分支及当前路径；分类异常或读取失败显示已保存但待同步，重试只恢复当前组合已加载范围与路径，不重放写入。Provider 的 `TreeNodeNotFoundError` 明确表示节点不存在，与网络、权限及路径损坏区分。

Tree View 的 `searchEnabled` 缺省为 true；显式 false 时不挂载搜索入口或发起搜索请求，Provider 不以假空结果代替未提供的能力。合成节点可通过可选 `labelKey` 使用词典标题，`label` 保留回退显示值。当前账号切换时，导航组合释放本地树、节点内容及旧异步请求；地址中的旧出现位置仍由新主体重新验证。

标准页面同步以最近一次已报告的 dirty/submitting 状态为准：清理表单可能立即释放组合排队的成功事实，即使 React 尚未提交新状态或其他读取者仍在异步同步，也不能被旧订阅闭包误判为仍脏而丢失列表刷新。真实未保存、提交中及非活动页面继续延期，恢复后只读刷新，不重复写入。

Tree View 的 `treeActions` 与节点 `contextMenu` 都是可选数组，缺省为空并按声明顺序展示。每项用 `viewKey` 指向已有 List View，并在 `standardAction` 与稳定 `actionKey` 中二选一；`actionKey` 引用该资源既有 ActionSchema 的 key，不重定义 handler、权限、确认或输入。目标身份及创建范围由可选 `inputResolverKey` 提供。候选校验拒绝重复 key、缺失／歧义动作及不匹配的资源 binding；实际资源装载继续核对 handler/input 注册。菜单先完成选择保护，标准 Host 随后复用同一 Drawer、行操作确认、Action Review Dialog 和共享执行。模块专用动作仍按原 handler key 执行并使用原服务端领域裁决。

树与标准列表共用共享 UI `ContextActionMenu` 的鼠标／键盘打开、关闭与焦点恢复；无菜单及输入编辑区域保留浏览器行为。Provider 节点可选 `contextMenuKeys` 只收窄节点类型已声明的菜单 key，空数组不显示菜单，未知 key 不能贡献新动作；缺省保持声明集合。该投影不授予功能或业务资格，也不改变 nodeType 和已有功能位置。树在选择／未保存内容保护通过后才打开目标菜单，执行前核对当前节点、主体、范围与活动状态；目标切换关闭菜单并拒绝旧隐藏项。

树菜单保留既有 `contextMenu` 静态呈现位置，列表保留 `list.rowActions` 位置，角色须分别获得所需位置。功能编译先按引用解析原 List View 的唯一动作，再从该动作的 `standardAction/handlerKey` 派生执行行为及其表单 Lookup／`readBehaviors`；引用 key 不等于执行行为。不同位置仍绑定同一真实 endpoint，不能为菜单另造行为或遗漏附加读取。

## Language

自定义导航可以通过 `featureKey` 保留自己的主行为，并用 PageRef 组合标准 Tree/List/Detail。候选编译器将这些标准页面的读取行为及业务动作派生到同一入口；初始化命令仍绑定导航原有主行为，派生读取不能用于 POST。动作位置保留 node-type、surface 和入口依赖，不复制第二份功能目录。

**页面（Page）**：
可通过稳定身份引用、在导航入口或组合中呈现的已注册界面，包括平台标准页面和模块自定义页面；它不必拥有独立菜单或地址。
_Avoid_: View 定义、菜单项、URL、React 节点

**视图（View）**：
供页面使用的命名配置定义，例如列表、详情、树或标签页的结构；页面通过参数接收所需视图，自定义页面不必要求视图配置。
_Avoid_: 页面实现、页面地址

**页面引用（PageRef）**：
由目标页面的稳定标识与固定页面参数组成的引用，用于声明导航或内容组合；视图引用可作为页面参数，当前节点等运行时上下文单独传入。
_Avoid_: ViewRef、Link、URL、业务关联

**树数据 Provider（Tree Data Provider）**：
使用一致节点身份提供根节点、直属子节点、搜索与祖先路径事实的数据能力；可以是配置驱动的平台标准实现，也可以是模块自定义实现。它拥有数据解释，不拥有页面布局或切换状态。
_Avoid_: 树存储引擎、父级候选 Lookup、宿主业务查询

**树节点描述（Tree Node Descriptor）**：
由树数据 Provider 提供的统一节点投影，表达节点身份、类型、显示信息、子节点存在性及模块上下文；它可以来自业务实体或计算结果，不要求 Tree View 映射业务字段。
_Avoid_: 业务实体 DTO、Company 字段映射、树存储记录

**树节点路径（Tree Node Path）**：
从根到目标、包含目标的有序节点标识与显示名称序列，用于展示完整路径及解析定位；搜索结果携带的路径表示搜索时的事实，定位时重新解析当前路径。
_Avoid_: 仅供展示的路径文本、永久有效的搜索快照

**通用树管理页面（Standard Tree Management Page）**：
以 Tree View 为配置，提供左侧搜索与树、右侧当前节点内容及节点操作的标准页面；既能从导航打开，也能作为组合中的页面内容。
_Avoid_: 组织专属树页面、仅有树控件

**通用标签页页面（Standard Tab Page）**：
以 Tab View 为配置，按标签装载页面并协调选择与生命周期的标准页面；其标签内容不限于使用 View 配置的标准页面。
_Avoid_: Tree View 私有标签、只能承载 View 的容器

**Tree View（树视图）**：
供通用树管理页面使用、声明树能力、节点类型、节点对应页面与节点菜单的视图配置；它不定义组织层级或其他模块的业务规则。
_Avoid_: 组织模型、部门层级、通用树存储

**Tab View（标签页视图）**：
供通用标签页页面使用、独立声明有序标签及各标签 PageRef 的视图配置；被引用页面可以接收另一个 View 作为参数，也可以是不需要 View 的自定义页面。
_Avoid_: Tree View 私有标签、Link、已打开对象列表

**标签页组（Tab Group）**：
由同一 Tab View 定义的标签集合，包含各标签的身份、标题、顺序和默认选择；切换内容上下文不产生新的对象文档标签。
_Avoid_: 动态窗口集合、浏览历史

**节点上下文（Node Context）**：
树选择传递给页面或操作的节点身份及相关业务事实；其业务含义由模块解释，节点身份不自动等于业务对象主键。
_Avoid_: 全局筛选、宿主组织字段、隐式路由参数

**页面输入契约（Page Input Contract）**：
被引用页面对所需参数与上下文的显式声明；缺少必需输入表示该页面无法成立，不表示可以切换为另一个无上下文的内容。
_Avoid_: 默认全局查询、页面私有参数猜测

**页面实例（Page Instance）**：
一个页面在特定组合位置、参数与上下文中的呈现身份；复用同一页面或视图配置不意味着共享筛选、分页或选择状态。
_Avoid_: View 定义、全局页面状态

PageOutlet 为标准列表与详情页面提供标准宿主环境的嵌入 adapter：不拥有地址，生命周期与成功事实经组合运行时交接，呈现模式由 PageRef 参数解析一次。

资源仅被 Tree/Tab 的 `platform.detail` PageRef 消费时，关联 List View 只提供共享资源装载关系，不要求列表导航、列表查看动作或生成独立路由；实际被导航或 `platform.list` 消费的对象列表仍必须提供唯一导航或明确组合位置及详情入口。
