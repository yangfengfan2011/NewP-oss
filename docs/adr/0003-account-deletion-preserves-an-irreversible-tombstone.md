# 账号删除保留不可恢复墓碑

Identity 对外提供删除账号的明确操作，但只有从未绑定人员的账号可以删除；已经建立人员账号绑定的账号永久禁止删除，只能停用。删除不会物理移除 User，而是保留 EID 不变的不可恢复墓碑，同时物理删除对应 LocalCredential、撤销全部认证会话并写入安全事件；这些变化必须在同一事务中提交，任一步失败时全部回滚。账号不能再登录、出现在账号目录中或建立人员账号绑定，当前使用的 ECODE 永久保留。相比允许先解绑再删除，这一规则保持永久绑定不变量；相比可恢复软删除，它避免“删除”与“临时停用”形成两套相近且容易误用的恢复流程，也避免永久保存已无认证用途的密码哈希。

跨上下文账号目录和 Identity 默认管理列表都排除已删除账号；Identity 管理员可以通过显式 `Deleted` 状态筛选查看只读墓碑详情、删除时间及关联安全事件，但任何编辑、恢复或绑定入口都不可用。这样既不让墓碑重新进入日常业务选择，也保留运营追溯能力。

删除界面必须展示 ECODE、ENAME、当前状态和不可恢复警告，要求管理员填写操作原因并手工输入完整 ECODE 后才能提交；服务器仍重新验证 Revision、人员绑定标记和本地管理员保护，不能把前端确认视为授权或不变量证明。
