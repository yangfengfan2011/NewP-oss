# 详细设计模板

## 1. 背景

- 这次要解决什么问题
- 为什么现在做
- 与当前阶段目标的关系

## 2. 目标

- 明确本次设计要达成的结果

## 3. 非目标

- 明确这次不做什么
- 明确哪些内容即使相关，也不纳入本轮

## 4. 范围

- 涉及哪些模块、目录、系统边界

## 5. 设计约束

- 架构约束
- 兼容性约束
- 性能/安全/权限约束
- 迁移约束

## 6. 总体方案

- 方案概述
- 为什么选这个方案
- 为什么不选其他方案

## 7. 关键模型

- 领域对象
- DTO / 配置模型 / 前端状态模型
- 模块间契约

## 8. 核心流程

- 主流程
- 异常流程
- 关键交互时序

## 9. 接口与集成点

- 后端接口
- 前端接入点
- 与其他模块或宿主的集成方式

## 10. 数据与状态

- 数据来源
- 存储方式
- 生命周期
- 一致性要求

## 11. 错误处理与风险

- 可能失败的点
- 风险控制方式
- 回滚或降级思路

## 12. 验证方案

- 需要跑哪些 build / test / smoke
- 如何证明设计已经按预期落地

## 13. 未决问题

- 当前仍未定的点
- 需要谁确认

## 14. 实施拆分建议

- 推荐按什么顺序落地
- 每一步的最小交付是什么
