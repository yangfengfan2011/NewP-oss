# ADR-0054：文件夹内容对象的编辑、删除与列表选择

状态：已接受（本次用户确认对象删除清理全部引用、非空文件夹阻止删除）。

Workspace 的内容行使用 LID 定位当前出现位置，服务端从实际关系取得对象类型和 EID。编辑及删除要求完整空间位置、父文件夹 edit、对象 read 及目标 edit/delete 数据权限。空间根不开放编辑和删除。文件夹改名检查所有直接父文件夹中的同名冲突，不泄露不可见父路径。

Part/Document 拥有标准 update/delete 对象行为和字段规则，Workspace 只通过稳定行为键组合，普通 HTTP 更新和删除端点暂不开放。Workspace 协调对象删除及全部入向引用清理，非空文件夹拒绝删除。混合批量删除采用同一事务和文件夹图锁，任一失败整批回滚，不递归删除后代。

批量范围为当前页勾选行（每页最多 100 条）；后端同样限制一次 1–100 个不同 LID。完整引用清理与冲突检查在数据库执行，不物化全部入向关系。共享列表 pageAction 可声明 requiresSelection，宿主据此显示受控多选、无选择禁用，向动作传入 selectedRows 快照。查询、位置、主体或数据刷新变化清空勾选，确认期间不能把新勾选混入原命令。动作功能身份沿用原 pageActions/rowActions 协议。

编辑输入使用共享 Drawer；批量删除使用共享确认容器。共享 Shell 不解释对象类型或删除规则。非目标包括回收站、递归删除、跨页全选、根文件夹管理、版本或乐观并发字段。

回退可撤销新增动作与选择契约，并恢复模块行为声明；不变更数据库结构。物理删除的数据只能通过数据库备份恢复，代码回退不恢复已删除对象。
