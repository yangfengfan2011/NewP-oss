# 首阶段认证只支持单 Host 并持久保护密钥环

首阶段认证部署契约只支持一个活动 Host 实例，不承诺多个实例共享 Cookie 或会话；但正常停止、启动和应用更新不得使未过期且未撤销的会话失效。Host 必须使用稳定的 Data Protection 应用名，并将密钥环持久化到安装或发布目录之外、可由运行身份持续访问的受保护位置；密钥必须显式加密保存，旧密钥在仍可能解析有效 Cookie 时不得删除。生产环境发现密钥位置不可读写、静态保护不可用或应用名不稳定时，必须以稳定诊断码 `AUTH_KEY_RING_INVALID` 拒绝启动，不能自动退回易失密钥。

会话注册表与 Data Protection 密钥环是两个独立的恢复条件：前者保留服务器端会话事实，后者保证 Host 能解析客户端 Cookie，任一丢失都不能宣称实现了重启恢复。共享密钥环、共享会话验证、并发密钥轮换和多实例故障切换作为后续独立能力设计，不通过当前单实例文件路径偶然共享。Development 可以自动建立隔离的本地开发密钥目录，但不得复用生产密钥材料。
