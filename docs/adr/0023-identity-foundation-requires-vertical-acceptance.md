# 身份基础能力以真实纵向旅程作为完成门槛

该能力只有在新数据库上通过完整纵向旅程后才算完成：Host 首次启动因未 bootstrap 而 Not Ready；离线命令初始化本地管理员；临时凭据登录后只能首次改密；随后完成账号创建、分页筛选、ENAME 修改、启停、凭据重置与不可恢复删除，并证明停用、删除或重置使全部旧会话在下一次请求失效。正常 Host 重启后，未过期且未撤销的会话必须继续有效。

Organization 旅程必须证明人员可以在公司与部门同时为空时创建和更新，半套组织归属会被拒绝，完整归属仍受存在、启用和部门隶属校验；还必须证明永久绑定、禁止解绑/改绑/删除、停用人员与账号/Hold/会话/事件的同事务提交，以及注入任一失败后所有状态完全回滚。安全旅程必须覆盖防伪令牌获取与单次刷新、登录限流、统一 ProblemDetails、一次性秘密不缓存和受限会话端点白名单。验收同时包含后端集成测试、正式 API、真实浏览器操作和数据库重启恢复证据；单元测试、直接数据库断言或跳过 Shell 的临时入口都不能单独替代完成裁决。
