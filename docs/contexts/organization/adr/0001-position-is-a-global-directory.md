# 岗位是 Organization 的全局目录

Organization 将岗位（Position）定义为可被任意人员独立引用的全局人员分类，而不是隶属于公司或部门的组织节点，也不是授权角色。岗位以全局唯一的 `ENAME` 作为名称，拥有可选描述和启用状态，并通过 Standard CRUD 提供管理入口；人员的岗位引用与公司、部门归属彼此独立。

这一选择避免各部门重复维护同一岗位，并让人员在没有组织归属时仍可选择岗位。停用岗位不再允许新分配，但保留既有引用；岗位只有在当前无人引用时才能删除，数据库使用可空且限制删除的人员外键保证引用完整性。未来若需要部门专属编制、任职期间或历史名称，应建立独立的岗位分配概念，而不是把公司或部门归属重新加回 Position。
