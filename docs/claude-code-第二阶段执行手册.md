# Claude Code 第二阶段执行手册

## 1. 这份手册解决什么问题

这份手册专门给 Claude Code 使用，用来避免它在第二阶段做出下面这些常见错误：
- 只把框架搭出来，却没有登录闭环
- 一上来就做完整身份平台
- 没有默认管理员，导致本地无法验证
- 跳过主界面与 Demo Module 联调，导致“看起来有代码，实际上跑不通”
- 在第二阶段就把范围扩到 WinApp、Studio、文件服务

## 2. Claude Code 在第二阶段的唯一主线

第二阶段只做一件事：

**把 `NewP` 推进到最小可运行平台状态。**

这个目标必须转化为下面的可见结果：
- 能启动
- 能登录
- 有主界面
- 有受保护的 Demo 页面
- 能退出登录并重新拦截

## 3. Claude Code 在开始前必须知道的内容

### 3.1 当前范围

纳入：
- Host
- Shell
- Identity Lite / LocalAuth
- Authorization
- ConfigCenter
- Audit
- Demo Module

排除：
- WinApp
- Studio
- 文件服务重写
- 工作流
- 报表与设计器
- 大规模旧页面兼容

### 3.2 当前仓库不是空壳

Claude 必须知道：
- 已存在 `ICP-Platform.sln`
- 已存在 `apps/host-api`
- 已存在 `frontend/package.json`
- 已存在 `server/modules/*`
- 已存在 `tests/*`

因此，第二阶段不是“从零假设”，而是在已有骨架基础上继续推进。

### 3.3 第二阶段不是文档阶段

文档已经足够多了。
第二阶段的主工作应转向：
- 代码实现
- 闭环验证
- 缺口修复

## 5. 每一步的成功标准

### Step 1 成功标准
- Host 能启动
- 契约存在
- Demo Module 能接入后端

### Step 2 成功标准
- 登录页可访问
- 前端能 build
- Demo 页面挂载点存在

### Step 3 成功标准
- 可登录
- 可获取当前用户
- 可退出登录

### Step 4 成功标准
- 首次启动可直接用默认管理员登录
- 重复启动不重复造脏数据

### Step 5 成功标准
- 登录后进入主界面
- 未登录不能访问受保护页面
- 退出登录后再次访问会被拦截

### Step 6 成功标准
- Demo 菜单可见
- Demo 页面可访问
- Demo 页面受保护

### Step 7 成功标准
- 可以完整演示一遍：
  - 打开登录页
  - 登录
  - 进入主界面
  - 打开 Demo 页面
  - 退出登录

### Step 8 成功标准
- 构建、测试、类型检查尽量清零

## 6. Claude Code 容易踩的坑

### 坑 1：把登录和授权做成一个模块

必须拆开理解：
- Identity Lite / LocalAuth：当前是谁
- Authorization：当前能做什么

### 坑 2：没有默认管理员

如果没有默认管理员，第二阶段的本地验证体验会非常差。

### 坑 3：前端有登录页，但没主界面闭环

“能登录”不等于“平台可运行”。
必须继续打通主界面、菜单、受保护页面。

### 坑 4：看见 `Files` 目录就开始做文件服务

第二阶段不要这样做。

### 坑 5：看见旧平台有大量页面，就想做兼容

第二阶段不要这样做。

## 7. 建议 Claude Code 在每步结束时输出什么

每步结束后都要输出：
- 本步改了什么
- 成功标准达成了哪些
- 没达成哪些
- 下一步建议直接做什么

## 8. 如果要并行

建议并行方式：
- 主线程：当前主任务实现
- 子代理：只读探索 / 契约审查 / 文档核对 / 最后测试修复

可参考：
- `docs/prompts/13_通用subagents触发模板.md`
- `docs/prompts/14_通用Worktree任务模板.md`

## 9. Claude Code 不应自己做的决策

如果遇到以下情况，Claude 不应自行扩大范围：
- 要不要做完整用户中心
- 要不要接外部统一认证
- 要不要把文件服务也一起做了
- 要不要兼容旧 `.aspx`
- 要不要把工作流、报表一起推进

这些都应该维持“不做”，除非用户明确改变范围。

## 10. 第二阶段完成后，Claude 才可以继续考虑

- `Authorization` 深化
- `ConfigCenter` 导入 POC
- `Audit` 深化
- 元数据迁移落地

在第二阶段没闭环前，不要越过这条线。
