# 导航与树通过 PageRef 组合页面，View 作为页面配置

NewP 需要在组织结构树右侧按节点类型展示不同标签页组，也需要让导航直接打开多标签页页面。平台通过 PageRef 引用已注册页面，将 Tree View、Tab View 等作为目标页面的配置参数；Organization 始终拥有组织数据与领域规则。页面是被组合的界面，View 是配置，二者不合并为同一种身份。

这是[组织结构管理与通用 Tree Host 决策地图](https://github.com/yangfengfan2011/NewP/issues/173)已确认的目标设计。首个实施切片已提供受控 PageRef、Tree/Tab 配置校验、组织树四类读取，以及公司直属部门创建和编辑的组合页面；标准 CRUD 与详情继续复用原定义，组合统一聚合未保存与提交状态，并将写入成功与后续读取失败分开。统一组织管理入口及结构维护已接入共享成功事实与非活动页面延迟同步；搜索呈现仍由 [交付地图 #179](https://github.com/yangfengfan2011/NewP/issues/179) 的后续切片完成。本 ADR 固定边界、非目标与回退方式；字段级契约及验收要求以该地图确认的规格为准。

## 边界与取舍

Provider 的归属与字段映射边界已由 [ADR-0047](0047-standard-relation-trees-use-configured-providers.md) 扩展：常规树可使用平台配置驱动 Provider，特殊业务继续拥有自定义实现。以下模块 Provider 描述保留原决策语境，当前标准关系树以 ADR-0047 为准。

- 导航、Tab 和树右侧使用 PageRef，声明目标页面的稳定标识与页面参数。标准列表、详情、树和标签页页面通过参数接收相应 View；模块自定义页面可使用自己的参数而不要求 View、独立菜单或 URL。此前把 ViewRef 作为组合目标的表述由这一页面／配置分工替代；Link 继续保留关系模型语义。
- 平台提供明确的通用树管理页面和通用标签页页面，分别消费 Tree View 与 Tab View。通用树管理页面拥有左侧搜索与树、右侧节点页面以及节点操作；不能只交付树控件或要求 Organization 自建管理页面。标准页面可由导航直接打开，也可经同一受控入口嵌入组合，页面外框与路由由外层协调。
- Tab View 是独立视图配置，标签由元数据固定声明，各标签通过 PageRef 引用页面。Tree View 按节点类型声明右侧 PageRef；当目标是通用标签页页面时，以参数提供对应 Tab View。页面与视图配置形成的组合必须显式、无循环，各层拥有自己的选择状态，内容不限于 CRUD 页面。
- 元数据声明静态结构与稳定引用，运行时代码负责装载、选择、状态与执行。Model、List View、Detail View 继续分别拥有字段／表单、列表和详情结构，组合不复制这些定义，不恢复任意列表区域回调。
- PageRef 中的固定页面参数与运行时上下文分开。View key 等配置静态声明，当前节点经统一页面接口传入，由模块解释为业务输入；metadata 不包含 CompanyId 等计算表达式。
- Tree View 通过一个稳定 key 绑定树数据 Provider，由同一 Provider 提供根节点、直属子节点、搜索与路径解析，保证节点身份一致；不分别声明 API 地址。Provider 实现与组织查询规则归模块，宿主只消费公共契约。
- Provider 返回统一树节点描述，提供节点身份、节点类型、显示信息、子节点存在性与模块上下文；既可投影业务实体，也可返回计算节点。Tree View 按节点类型配置右侧 PageRef 和菜单，不声明 Company.Name 等业务字段映射，公共宿主不从模块 DTO 猜测节点含义。
- 模块提供树读取、全树搜索、路径与节点上下文解释。公共 Tree Host、Tab Host 不认识 CompanyId、ParentDepartmentId 或模块 ID；节点身份不被当作通用业务主键，模块也不通过刷新回调控制宿主内部状态。
- 被引用页面通过页面输入契约显式声明所需参数与上下文；缺少必需输入时拒绝加载并显示配置／上下文错误，不能将直属列表悄悄回退为全局列表。View 只拥有页面配置，不拥有页面接入或生命周期接口；输入校验不替代模块的业务查询和写入校验。
- 每个页面实例隔离筛选、分页和选择状态。同一节点下切换标签保持其内容状态，切换节点重置内容状态；有未保存输入时先完成已确认的离开保护。内嵌页面不直接改写整个页面 URL，路由恢复由外层负责。
- 标准与自定义页面通过统一接口报告未保存修改及正在提交的状态，外层组合聚合并决定离开保护。保护覆盖整个当前组合，包括已打开但未激活的标签；取消离开时保留原上下文与输入，不能让各页面分别放行同一次外层切换。当前页面内部的 Drawer 确认不是已经可供组合复用的公共接口。
- 创建、编辑与删除复用既有 Standard CRUD 执行机制。共享宿主协调受影响树分支与当前内容的刷新，未激活的相关内容下次打开时刷新；写入成功与随后读取失败分别表示，刷新重试不能重放写入。

组织是首个真实采用者，不是公共契约的模板。后续导航采用一个组织管理入口组合组织结构与四个全局目录；这只替代[组织 ADR-0002](../contexts/organization/adr/0002-company-and-department-directories-use-standard-crud.md)的呈现与入口决定，公司／部门目录、层级、排序、生命周期、业务查询与存储归属继续成立。旧列表地址跳转及人员完整详情保持可访问的要求见[入口演进决策](https://github.com/yangfengfan2011/NewP/issues/178#issuecomment-5583422265)。

ADR-0031 的详情唯一事实源扩展到组合中的只读详情呈现；ADR-0036/0037 的共享执行 owner 保持不变，其单个呈现面刷新描述由本 ADR 的目标组合协调范围补充。动作与普通写入仍保留各自既有错误／冲突处理，不因组合引入 Revision 或自动重放。

## 非目标

不建设通用树存储、任意图平台或动态对象文档标签，不允许循环视图引用；当前不提供同级节点分页、拖拽或人员入树。树按层读取全部直属节点，搜索结果可分页，这一差异由读取决策拥有。权限相关设计暂不纳入本阶段。

本决定不改变组织业务模型与既有 CRUD 数据接口，不生成第二份字段／视图定义，不把目标规模写成未经测量的性能保证，也不把声明中的静态条件扩成脚本执行语言。

## 验证与回退边界

扩大实施前必须以真实 Organization authoring 经正式编译、runtime 投影和共享宿主完成选择公司、新增部门、右键编辑与结果可见的纵向检查点。状态与数据语义在最低适用层验证，浏览器调整既有 Personnel 主旅程；实际执行遵循 [quick-verification.md](../verification/quick-verification.md)，本次文档不代替实现或验证证据。

回退必须同步恢复公共契约、宿主、模块接入、导航／跳转与相关文档及验证资产，保留业务数据。不能只恢复一个引用方或为一条旧路径留下另一套内容实现。
