# Identity

Identity 是 Host 的必需内建上下文，管理可登录主体对应的用户账号与账号状态。Identity 应用层拥有本地凭据登录与账号安全命令的完整用例编排，通过稳定契约读取功能位置、协调普通账号准入并请求 Authentication 登记或撤销会话；它不拥有人员档案、授权角色、业务权限或认证会话数据。

账号列表、快照和详情普通字段复用 Standard CRUD 的查询与展示能力，但 Identity 不映射通用写入端点。账号创建必须原子签发凭据并记录安全事件，显示名称修改必须执行 Revision 条件替换，删除必须保留墓碑和 ECODE，启停、凭据重置与本人改密还要协调会话；因此这些写入继续由同一个 Identity 应用服务承担。Identity 不为这些用例注册对象动作、横切扩展或纯转发行为类，HTTP 与内部调用共同复用该业务核心及平台事务执行器。

## Language

**用户账号（IdentityAccount）**：
由 Identity 拥有、以 EID 作为稳定用户标识的账号安全聚合根；它以 ECODE 表达登录账号、以 ENAME 表达显示名称，可以被认证机制识别，也可以由其他上下文按 EID 引用。账号、显示名称、绑定标记和凭据安全变化共同递增其公开 Revision，LocalCredential 不另行暴露 Revision。
_Avoid_: 人员档案、已认证主体、角色

**登录账号（ECODE）**：
用户账号用于本地登录的全局唯一账号；输入经 Trim 与 Unicode NFKC 后长度为 3–64 个字符，只允许 Unicode 字母、数字及 `.`、`_`、`-`、`@`，不允许空格或控制字符。比较时不区分大小写，创建后不可修改；账号删除也不会释放 ECODE，其他上下文不得用它代替稳定用户标识建立引用。
_Avoid_: 用户标识、显示名称、人员编号

**登录账号保留（Account Code Reservation）**：
ECODE 首次分配后形成的永久占用规则；它由包含已删除墓碑在内的 IdentityAccount 记录及其规范账号唯一约束保证，不建立独立实体或数据表。
_Avoid_: 账号保留实体、可回收账号、显示名称占用

**显示名称（ENAME）**：
用户账号面向界面展示的可修改 Unicode 名称，Trim 后长度为 1–128 个字符，不用于登录、关联或唯一性判断；人员账号绑定不会在它与 Person.Name 之间进行复制或自动同步。
_Avoid_: 登录账号、用户标识、人员姓名

**操作原因（Operation Reason）**：
管理员执行账号安全生命周期命令时提供的说明；Trim 后长度为 1–500 个字符，允许多行，并随安全事件永久保留。
_Avoid_: 显示名称、普通备注、可选审计字段

**账号目录（Account Directory）**：
Identity 提供的可查询用户账号集合，用于验证账号存在并支持其他上下文建立受控引用；它不包含已删除账号。
_Avoid_: 人员目录、角色目录、权限目录

**账号状态（Account Status）**：
用户账号在 `Enabled`、`Disabled` 与不可恢复终态 `Deleted` 之间的显式生命周期状态；停用立即阻止新登录并撤销既有会话，删除后不能恢复。人员停用阻断与人员绑定标记是独立约束，不是账号状态值。
_Avoid_: 多组状态布尔值、人员状态、任职状态、授权状态

**人员停用阻断（Personnel Disable Hold）**：
关联人员处于停用状态时施加在用户账号上的启用阻断；人员恢复只解除阻断，账号仍须通过显式操作恢复。
_Avoid_: 自动恢复、账号权限、人员账号关联

**人员绑定标记（Personnel Binding Marker）**：
账号曾经完成人员账号永久绑定的单调事实；它不包含 Person EID，初始为否，绑定后永久为是，并独立阻止该账号被删除。
_Avoid_: 人员引用、可解除绑定、人员停用阻断

**已删除账号（Deleted IdentityAccount）**：
仅从未绑定人员的账号可以进入并保留 EID 的不可恢复账号墓碑；它不能登录、出现在账号目录中或建立人员账号绑定，已经绑定人员的账号永远不能删除。管理员只能通过显式筛选查看其只读详情和安全事件。
_Avoid_: 物理删除、停用账号、可恢复账号

**本地凭据（Local Credential）**：
与一个用户账号一对一关联并由 LocalAuth 独立管理的认证凭据；它只保留可验证的密码哈希和临时凭据状态，不保存可找回的明文秘密。用户自助修改凭据时必须再次验证当前凭据且新密码必须不同；IdentityAccount 删除时凭据在同一事务中物理删除。
_Avoid_: 权限、角色、Cookie、明文密码

**正式密码（Permanent Password）**：
用户完成首次凭据修改后用于正常认证的本地密码；按 Unicode 字符计数，长度必须为 8–64 个字符，保留用户输入的首尾空格且不自动裁剪、转换大小写或规范化，但全空白值无效。不设置字符组合或常见密码黑名单。
_Avoid_: 临时凭据、隐式 Trim、复杂度评分、定期轮换密码

**临时凭据（Temporary Credential）**：
创建已启用账号或管理员重置时签发、只展示一次且必须在首次登录后更换的本地凭据；它只能建立受限认证会话，不能直接作为正式密码保留。明文只存在于成功响应和当前一次性结果界面，关闭后不能重新查看。
_Avoid_: 永久密码、可找回密码、默认密码

**本地认证（LocalAuth）**：
使用本地凭据认证 Identity 用户账号的认证方式；它不拥有用户账号或账号状态。
_Avoid_: Identity、账号目录、授权

**本地管理员（Local Administrator）**：
Identity 为空时通过服务器本机命令一次性初始化的受保护用户账号；它的 ECODE 不可修改，且不能被停用、删除或建立人员账号绑定，只能通过本机维护命令重置临时凭据。
_Avoid_: 可删除管理员、自动恢复账号、权限绕过主体

**身份安全事件（Identity Security Event）**：
Identity 对 ECODE、ENAME 与凭据生命周期变化永久保留的不可修改事实；操作者使用 `IdentityAccount`、`LocalMaintenance` 或 `System` 类型表达，并按需引用 Actor Account EID。事件还包含固定事件类型、原因、时间、目标 Account EID 与 TraceId，但不包含操作者名称副本或任何明文凭据；首阶段不提供删除或自动清理。
_Avoid_: 普通访问日志、可编辑备注、明文秘密
