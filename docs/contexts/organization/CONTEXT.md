# Organization

Organization 上下文管理组织主数据与人员档案。它描述人员属于哪个组织，不拥有登录账号、凭据或授权分配。

组织结构页面现由 `platform.relations` 消费 Organization 的公司、部门关系配置，读取走 `/api/trees/organization.structure/*`；页面输入和业务写入仍由 Organization 解释。原有组织专用树 API 保持既有行为，结构页面不再注册专用前端 Provider。

组织树读取由本模块提供根、直属子节点、分页搜索和当前路径；节点上下文由模块解析为标准页面输入。公司直属部门范围显式使用空上级，查询范围与用户筛选相交并在总数、分页前执行。组织管理统一入口组合组织结构与公司、部门、岗位、人员四个全局目录；全局部门通过显式解析器移除节点上下文与固定创建值，以 `queryScope: { kind: "global" }` 向本模块声明全局资源语义。空范围和不完整直属范围仍拒绝，全局范围不得混入直属字段。旧目录地址跳转到对应标签，人员完整详情由导航 metadata 独立声明。完整结构操作及搜索呈现见 [交付地图 #179](https://github.com/yangfengfan2011/NewP/issues/179)。

## Language

**人员档案（Person）**：
组织中的业务人员记录，拥有独立人员标识，并可在组织结构能力可用后建立组织归属；它不等于可登录的用户账号。
_Avoid_: 用户、账号、员工账号

**出生日期（Date of Birth）**：
人员档案记录的完整日历日期，年份是该事实的一部分；它不表示时间点，不按查看者时区转换，也不承担每年重复的生日提醒语义。
_Avoid_: 生日、出生时间、年龄

**入职时间（Employment Start Time）**：
人员档案当前或最近一次任职区间预定或实际开始的时间点；它使用 UTC 原始值，并按查看者的有效时区展示，但不自动改变任职状态或人员启用状态，也不构成任职历史。
_Avoid_: 创建时间、启用时间、任职状态

**离职时间（Employment End Time）**：
人员档案当前或最近一次任职区间预定或实际结束的时间点；它使用 UTC 原始值，并按查看者的有效时区展示，但不自动改变任职状态或人员启用状态，也不构成任职历史。
_Avoid_: 删除时间、停用时间、任职状态

**公司（Company）**：
人员和部门所属的顶层组织主体；公司名称在 Organization 范围内唯一。
_Avoid_: 租户、客户、法人账号

**公司编码（Company Code）**：
在 Organization 范围内唯一标识公司的稳定业务编码，创建后不可修改。
_Avoid_: 公司名称、租户编号、公司 EID

**公司启用状态（Company Enablement Status）**：
表示公司当前是否允许新增部门或建立新的人员组织归属；停用公司保留既有引用，但公司仍有启用部门时不得停用。
_Avoid_: 删除状态、人员启用状态、账号状态

**部门（Department）**：
隶属于一个公司的组织单元，可具有同公司内的上级部门；部门名称在同一上级下唯一。
_Avoid_: 团队、用户组、授权组

**部门编码（Department Code）**：
在所属公司内唯一标识部门的稳定业务编码，创建后不可修改。
_Avoid_: 部门名称、部门 EID、全局部门编号

**部门层级（Department Hierarchy）**：
部门通过可选的同公司上级形成无环层级；部门创建后不能迁移到另一公司，但可以在原公司内调整上级。
_Avoid_: 组织树页面、授权层级、跨公司部门移动

**部门启用状态（Department Enablement Status）**：
表示部门当前是否允许新增子部门或建立新的人员组织归属；停用部门保留既有人员引用，但仍有启用子部门时不得停用。
_Avoid_: 删除状态、人员启用状态、账号状态

**排序码（Sort Order Code）**：
公司和部门用于形成稳定展示顺序的字符串编码。它由 1–32 个 ASCII 数字组成，保留前导零并按完整字符串字典序升序比较；重复排序码以公司或部门编码稳定排序，不能按整数解析、补齐或规范化。
_Avoid_: 排序数字、数值权重、自然数序号

**组织归属（Organization Affiliation）**：
人员档案可选的公司与部门组合。公司和部门可以同时为空；新增或改变归属时，两者必须成对出现，部门必须属于该公司，且二者都处于启用状态。公司或部门后来停用时保留既有归属，并允许人员维护与归属无关的信息；岗位不属于组织归属，人员可以独立选择岗位。
_Avoid_: 用户组成员关系、授权归属、原始组织 ID

**岗位（Position）**：
Organization 范围内共享的全局人员分类，可供任意人员独立选择；它不隶属于公司或部门，也不等于授权角色。
_Avoid_: 部门岗位、角色、权限角色

**岗位启用状态（Position Enablement Status）**：
表示岗位当前是否允许分配给人员；停用岗位不会清除既有人员引用，既有引用仍可显示。
_Avoid_: 人员启用状态、账号状态、删除状态

**任职状态（Employment Status）**：
人员的任职类型，例如全职、兼职、合同工或实习；它不表达记录是否可用，也不等同于离职流程。
_Avoid_: 在职状态、启用状态、账号状态、离职状态

**人员启用状态（Person Enablement Status）**：
人员档案当前是否启用的独立状态；停用不改变任职状态，但必须同时停用通过人员账号绑定指向的用户账号，恢复人员则不会自动恢复账号。
_Avoid_: 任职状态、账号状态、删除状态

**用户账号（User）**：
由 Identity 拥有、可被认证机制识别的账号；Organization 最多通过显式关联引用其标识。
_Avoid_: 人员档案、员工

**人员账号绑定（Person-User Binding）**：
启用人员与用户账号之间由 Organization 拥有的永久一对一关系；账号可以在启用或停用状态下完成绑定，停用账号绑定后仍保持停用。绑定后双方都不能删除、解绑或改绑，人员停用会强制停用账号，但人员恢复不会自动恢复账号；Person.Name 与 User.ENAME 始终分别维护，不因绑定自动同步。
_Avoid_: 可解除关联、用户角色、组织成员关系、账号归属

**人员中心（Personnel Center）**：
围绕人员档案查询、查看和维护提供的管理入口，不代表完整组织树或身份管理系统。
_Avoid_: 账号中心、人力资源系统

**组织管理（Organization Management）**：
组合组织结构、公司、部门、岗位和人员管理内容的统一入口；入口组合不改变各资源的领域含义，也不表示岗位或人员属于组织树节点。
_Avoid_: 身份管理、组织模型、组织归属
