# 分流标签

Engineering skills 使用五个固定角色。本文件定义这些角色在当前 GitHub 仓库中对应的实际标签。

| Engineering skills 角色 | GitHub 标签       | 含义                         |
| ----------------------- | ----------------- | ---------------------------- |
| `needs-triage`          | `needs-triage`    | 等待维护者评估               |
| `needs-info`            | `needs-info`      | 等待报告者补充信息           |
| `ready-for-agent`       | `ready-for-agent` | 规格完整，可交给无人值守 agent |
| `ready-for-human`       | `ready-for-human` | 需要人工实施                   |
| `wontfix`               | `wontfix`         | 不会处理                       |

当技能描述某个角色时，应使用表中对应的 GitHub 标签。

如果仓库以后改用其他标签名称，只需修改第二列，不要改变第一列的标准角色。
