# Platform SDK

## Goal

Make extension module development boring, repeatable, and contract-first.

## Server SDK should help with

- module registration
- permissions
- menus/routes
- config declarations
- migration/import hooks
- test setup

## Frontend SDK should help with

- route registration
- menu registration
- permission guards
- shell integration
- i18n registration
- page bootstrapping

## Non-goals

- business-specific shortcuts
- hidden cross-module calls
- shell internals access
