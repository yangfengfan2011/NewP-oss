# 人员组织归属在首期是可选组合

公司与部门能力尚不能作为人员维护的前置条件，因此 `Person.CompanyId` 与 `Person.DepartmentId` 在创建和编辑时都不再标记为必填，并允许二者同时为空。人员工号、姓名、任职状态与启用状态的现有必填语义不受影响；岗位的现有可选语义也不在本决策中扩展。

可选不代表允许悬空或半套归属：只要公司或部门任一字段有值，另一字段也必须有值，且公司、部门必须存在并启用，部门必须隶属于所选公司。编辑时允许同时清空公司和部门。当前持久化列与 DTO 已支持空值，因此本决策不新增数据库迁移；未来若要重新强制组织归属，必须通过新的显式设计处理既有无归属人员，不能仅收紧表单校验。
