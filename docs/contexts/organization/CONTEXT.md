# Organization

Organization 上下文管理组织主数据与人员档案。它描述人员属于哪个组织，不拥有登录账号、凭据或授权分配。

## Language

**人员档案（Person）**：
组织中的业务人员记录，拥有独立人员标识和组织归属；它不等于可登录的用户账号。
_Avoid_: 用户、账号、员工账号

**公司（Company）**：
人员和部门所属的顶层组织主体。
_Avoid_: 租户、客户、法人账号

**部门（Department）**：
隶属于一个公司的组织单元，可具有上级部门。
_Avoid_: 团队、用户组、授权组

**组织归属（Organization Affiliation）**：
人员档案所属的公司与部门组合；部门必须属于该公司，且二者在建立归属时都处于启用状态。岗位是可选的补充归属。
_Avoid_: 用户组成员关系、授权归属、原始组织 ID

**岗位（Position）**：
部门内的组织岗位，可供人员选择；它不等于授权角色。
_Avoid_: 角色、权限角色

**任职状态（Employment Status）**：
人员的任职类型，例如全职、兼职、合同工或实习；它不表达记录是否可用，也不等同于离职流程。
_Avoid_: 启用状态、账号状态、离职状态

**启用状态（Enablement Status）**：
人员档案当前是否启用的独立状态；停用人员档案不自动改变任职状态或用户账号状态。
_Avoid_: 任职状态、账号状态、删除状态

**用户账号（User）**：
由 Identity 或 LocalAuth 拥有的登录主体；Organization 最多通过显式关联引用其标识。
_Avoid_: 人员档案、员工

**人员中心（Personnel Center）**：
围绕人员档案查询、查看和维护提供的管理入口，不代表完整组织树或身份管理系统。
_Avoid_: 账号中心、人力资源系统
