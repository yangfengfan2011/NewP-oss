# 账号创建与临时凭据签发原子提交

普通账号创建命令在同一数据库事务中建立 Enabled User、与其一对一关联的 LocalCredential 哈希及临时凭据状态，并写入 Identity 安全事件；任一步失败都不得留下无凭据账号、孤立凭据或缺失安全事件的部分结果。临时凭据由安全随机源为该账号独立生成，事务内只持久化哈希，提交成功后才在受保护响应中展示一次，创建账号不会自动建立认证会话。

一次性明文不进入日志、事件、配置或可再次查询的数据结构；成功响应必须设置 `Cache-Control: no-store`，前端只在当前结果弹窗展示并允许显式复制，关闭弹窗后立即清除。如果成功响应丢失，客户端不能重放或查询原凭据，只能执行新的显式管理员重置。相比先创建账号再补凭据的跨请求流程，这一事务边界使账号从首次可见起就具备完整且可审计的认证状态，同时保持秘密不可恢复。
