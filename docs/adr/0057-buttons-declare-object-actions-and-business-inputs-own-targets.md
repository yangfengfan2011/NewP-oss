# ADR-0057：按钮声明对象动作权限，正式业务输入确定判权目标

状态：已确认；组织四资源基础增删改服务端、工作区排序、显式内部组合及对象要求数组公共管线已实施，其余入口和协议退役仍在分片迁移。

按钮的对象动作权限只在按钮定义中声明，由平台从业务操作的正式输入取得目标并自动判权；业务内部根据自身语义选择是否调用通用判权方法。该决定减少按钮、执行合同与后端接线之间的重复权限声明，同时保留业务对关联对象和判权时点的控制，不按业务复杂程度区分按钮类型。

## 唯一声明与目标

按钮使用以下形态：

```json
"dataAccess": {
  "object": "Person",
  "actions": ["edit"]
}
```

同一按钮可声明多个对象条目，原单对象形态继续有效。该边界由[父规格的已确认修订](https://github.com/yangfengfan2011/NewP/issues/322#issuecomment-6293750051)确定：

```json
"dataAccess": [
  { "object": "Part", "actions": ["read"] },
  { "object": "Document", "actions": ["read"] }
]
```

数组、条目与动作集合均不能为空；未知对象或动作、重复对象或动作、与旧执行形态混写均拒绝。每个实际规范目标必须匹配唯一对象条目并满足该条目的全部动作；本次实际目标全部通过后才执行业务，不要求每次调用包含声明中的所有对象类型。资源绑定只从正式对象目录派生，不增加作者配置或对象族。服务端 `ButtonTargetSet` 仅收集同一业务状态中的实际对象目标，逐项消费对应要求；标量 `Object` 为空不代表数组没有要求。拒绝或依赖故障发生在任意一项时，实际业务回调均不执行。

`object` 引用已登记的对象名称，`actions` 引用已登记的数据授权动作；按钮不再配置目标来源、执行合同、provider、角色或阶段，也不在 Capsule 或后端绑定中重复声明同一要求。业务处理器绑定与全局动作定义继续分别拥有业务实现身份及动作本身的语义，运行时权限投影由平台生成。

正式业务输入契约明确本次操作目标或目标集合。平台解析、校验并规范化这些目标，对声明对象的每个目标检查全部声明动作，全部允许后才继续相应业务变更；不扫描输入中的所有同类型标识，也不另接收权限专用对象标识。来源、父对象和其他关联对象是否需要检查由业务决定；它们不因同类型而自动进入目标集合。目标定义属于业务输入契约，不形成另一份权限配置；配置了对象要求却无法取得有效目标时拒绝，不跳过检查或只执行允许子集。

权限检查与实际业务执行使用同一规范目标。创建沿用完整候选判权，既有对象沿用执行前事实；已有事务、协调、目标保护和业务约束继续生效，不把所有检查提前到事务之外，也不复用先前请求的允许结果。

## 平台自动判权与业务主动判权

平台按服务端生效的按钮定义及真实业务绑定执行入口检查，不接受客户端选择权限要求或提交允许结果。未配置 `dataAccess` 的按钮不自动增加对象动作要求；请求缺少有效按钮身份、声明无效或目标不匹配，不能解释为按钮未配置权限。功能位置资格仍遵循 ADR-0048。

业务实现自行决定是否调用通用判权方法，以及检查哪些对象、动作和时点，调用不要求另外登记权限执行合同。通用方法与按钮自动检查复用同一规则授权、对象授权、读取依赖和完整访问约束。内部业务调用不隐式继承按钮的允许结果，也不由共享持久化入口强制追加一份固定动作权限；业务需要的检查由业务明确调用。公开 HTTP 入口不能以漏传按钮身份冒充内部调用，既有纯 API 的访问约束保持各自归属。

多个按钮共享业务实现时，各自采用自己的按钮声明和功能位置；业务认为所有调用都必须满足的要求在业务中主动检查。事务、审计、系统强制隔离和业务必需校验不因未调用对象判权而取消。

## 替代范围与非目标

本决定替代 ADR-0052“执行合同与入口绑定”中对按钮权限普遍要求独立执行合同及固定数据权限下限的规定，并调整 ADR-0051 中共享写入来源必须承载该固定下限的要求；岗位编辑和工作区排序已按本决定迁移，显式内部对象组合可不附加数据动作下限；其他入口和现有执行合同说明仍表示各自当前事实。ADR-0052 的规则与对象授权语义、动作启停、读取依赖、管理员边界、编辑前判权及写后不可读成功语义继续适用。

列表、详情、lookup、树、导出及纯 API、内部读取不是按钮权限声明的同义词；本决定不统一删除其读取过滤或来源约束，不因改造给现有业务增加新的对象动作要求。不新增按钮分类、通用策略表达式、权限数据库结构或权限结果缓存。

## 回退

按完整按钮调用链恢复匹配的声明、业务绑定、请求适配与服务端执行实现，保留规则授权、对象授权、功能分配和审计数据。不能通过解析失败回退、缺声明放行或恢复未受保护的旧接口回滚。
