# Local Environment

## Recommended pinned versions

- .NET SDK: current LTS used by the new platform
- Node.js: team-approved LTS
- Package manager: npm or pnpm, choose one and pin it

## Local bootstrap checklist

1. install .NET SDK
2. install Node.js
3. restore backend dependencies
4. install frontend dependencies
5. run backend build
6. run frontend build

## Repository-specific placeholders

Update the following once the new repo exists:
- solution path
- frontend workspace path
- bootstrap commands
- local environment variables
- dev database or mock services
