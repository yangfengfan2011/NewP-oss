# Part

Part 拥有独立零组件元数据，不包含版本、BOM、文件内容或专业属性。`Part` 是真实 Entity，身份和审计由平台维护；`ECODE`、`ENAME` 显式采用 builtin，`Description` 使用可空长文本语义。

零组件编码必填且本模型内唯一，名称必填但不唯一。标准字段策略规范化名称与编码，模块在数据库侧按同一列比较规则预检编码；数据库唯一索引是并发保护事实源，竞争复用标准 409 冲突。说明可缺省，最多 500 字，服务端拒绝超长值。

稳定资源 `part.part` 提供 `/api/part/parts` 标准创建和读取，页面 `/parts` 使用共享标准列表与创建 Drawer，`part.part.detail` 提供只读属性 Drawer 和正式 `/parts/:id` 详情。创建提交后不可读或展示失败继续返回不含对象标识的成功回执，客户端只重试读取。

侧栏不提供独立零组件入口；用户从 Workspace 选中文件夹后新建，由 Workspace 在同一对象操作事务内调用 `part.part` 创建行为并建立内容关系。原页面路由保持 routeOnly；功能入口通过 `parentModuleId: Workspace`、`parentKey: workspace` 显式归入工作空间，详情和全部子操作共享这条授权祖先链，不再发布独立顶层授权入口。数据资源、对象行为和接口执行归属仍由 Part 拥有。

普通创建入口绑定 `part.part.create`，候选在服务端补齐身份、归属与审计字段后消费标准 create 下限。内部创建、更新和删除有各自的固定调用绑定，随对象操作的只读写来源传递，资源与目标不能由业务字段替换；目标仍在原事实保护位置执行自己的必要要求。尚未迁移的 Workspace 和真副本调用者只保留逐成员、逐动作登记的 typed legacy 边界，不能因缺绑定回退。

创建、更新与删除采用所属模块的标准对象行为，不开放横切。Workspace 通过稳定行为键组合更新与物理删除，字段规则及编码唯一性仍归对象拥有者；普通 HTTP 更新与删除端点保持关闭。插入与仓储规范重读在唯一平台事务内，规范重读失败整体回滚；提交后的读取裁决和展示故障由标准服务返回成功回执。

候选通过同一标准 GET 列表按编码或名称搜索、数据库分页和窄字段投影；正式功能读取资格与对象读取计划同时生效，可发现没有任何 Link 的独立零组件。当前没有真实 Lookup 字段消费者，因此不开放单独 Options 能力。后续 Workspace 通过稳定资源、模型显示与页面绑定消费，不依赖 Part 私有实现；本模块不拥有 Link 或混合内容查询。

文件夹内容入口提供编辑和删除，Workspace 在同一事务清理全部引用；独立页面继续只开放创建与读取，启停和导出保持拒绝。标准资源登记要求的对象授权能力使用现有正式功能声明，不引入额外权限系统。

所属对象独立声明 `partCopy` 数据动作（`data.part.copy`），要求 read，只供引用复制资格裁决，不克隆实体或执行 update/delete。显示词条由本 owner 的 DataScope 词典提供，Workspace 通过正式对象资格接口消费，目录关系与剪贴板仍归 Workspace。

`partObjectCopy`（`data.part.objectCopy`）独立控制真副本来源资格，要求 read，不从旧引用动作推导授权。`part.part.copy/copy` 由 Part owner 核对当前编码、名称和说明与确认来源一致，并调用正常 `part.part/create`；新编码与确认属性使用原字段规则、候选 create、唯一索引和可信审计。EID、对象审计重新生成，不复制旧审计或入向关系。复制字段分类与当前正式持久模型核对，新增实际字段未分类时失败关闭。Workspace 只编排完整出现位置、目标关系和结果，不克隆 Part 私表。

回退优先撤销 Part 导航与资源接入，保留独立实体及迁移历史。代码回退不自动执行 Down 或清表，旧 Host 不得越过已应用的 schema frontier。
