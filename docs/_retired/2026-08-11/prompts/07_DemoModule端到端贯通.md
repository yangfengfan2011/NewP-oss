请在新平台中创建一个最小 Demo Module，验证从后端注册到前端展示的全链路。

Demo Module 目标：
- 有模块元数据
- 有后端服务注册
- 有权限点声明
- 有菜单声明
- 有前端路由注册
- 有一个最小页面

重点不是业务，而是验证以下路径：
- 未登录用户不能直接访问受保护页面
- 登录后用户能进入主界面
- Host 能发现模块
- 模块能注册服务
- 菜单能聚合
- 路由能挂载
- 权限点能声明并被读取

限制：
- 不要接真实旧业务
- 保持实现最小
- 代码尽量作为后续模块模板使用

验证要求：
- 后端 build
- 前端 build
- 可通过登录后进入 Demo 页面
- Demo 页面可访问
- 菜单可见
