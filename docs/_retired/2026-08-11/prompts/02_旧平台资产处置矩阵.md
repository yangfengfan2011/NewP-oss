目标是把旧平台的主要资产按下面 5 类决策分类：
- Retire
- Rewrite
- Wrap
- Import
- Postpone

请至少覆盖以下资产类型：
- 宿主
- 公共代码模块
- 运行时元数据资产
- 旧页面与静态资源
- 数据与配置资产
- 外部集成能力

输出要求：

1. 先给“第一阶段纳入范围”的清单
2. 再给“第一阶段明确排除”的清单
3. 最后给完整表格，列出：
- 资产名
- 类型
- 当前位置
- 处置决策
- 目标模块或目标区域
- 决策原因
- 前置条件
- 风险

- 新平台内核优先 Rewrite
- 历史宿主尽量不要直接搬进新平台

- 一阶段只纳入平台成立必须项
- 不要把复杂业务能力塞进第一阶段
