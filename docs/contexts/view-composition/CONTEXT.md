# View Composition

视图组合定义 NewP 通过视图配置将页面组织为导航内容、树的节点内容和标签页组的公共语言。组合拥有页面的安排与上下文交接，页面所属模块拥有业务含义。

导航 metadata 的 `routeOnly` 项声明不生成菜单的受控地址，`redirectTo` 兼容项只跳转，不装载另一套列表。完整详情可通过 `entryType: standard-crud-detail` 与目标 binding 显式声明，独立于列表菜单和兼容地址。导航根页面拥有标题与 `tab` 地址状态；嵌套页面保持局部选择、筛选和分页。PageProps 的 `active` 表示整个父链是否可见，隐藏页面仍报告未保存／提交状态，但应隐藏 Portal 呈现；同一配置的实例使用独立查询身份。

## Language

**页面（Page）**：
可通过稳定身份引用、在导航入口或组合中呈现的已注册界面，包括平台标准页面和模块自定义页面；它不必拥有独立菜单或地址。
_Avoid_: View 定义、菜单项、URL、React 节点

**视图（View）**：
供页面使用的命名配置定义，例如列表、详情、树或标签页的结构；页面通过参数接收所需视图，自定义页面不必要求视图配置。
_Avoid_: 页面实现、页面地址

**页面引用（PageRef）**：
由目标页面的稳定标识与固定页面参数组成的引用，用于声明导航或内容组合；视图引用可作为页面参数，当前节点等运行时上下文单独传入。
_Avoid_: ViewRef、Link、URL、业务关联

**树数据 Provider（Tree Data Provider）**：
使用一致节点身份提供根节点、直属子节点、搜索与祖先路径事实的模块能力；它拥有数据解释，不拥有页面布局或切换状态。
_Avoid_: 树存储引擎、父级候选 Lookup、宿主业务查询

**树节点描述（Tree Node Descriptor）**：
由树数据 Provider 提供的统一节点投影，表达节点身份、类型、显示信息、子节点存在性及模块上下文；它可以来自业务实体或计算结果，不要求 Tree View 映射业务字段。
_Avoid_: 业务实体 DTO、Company 字段映射、树存储记录

**树节点路径（Tree Node Path）**：
从根到目标、包含目标的有序节点标识与显示名称序列，用于展示完整路径及解析定位；搜索结果携带的路径表示搜索时的事实，定位时重新解析当前路径。
_Avoid_: 仅供展示的路径文本、永久有效的搜索快照

**通用树管理页面（Standard Tree Management Page）**：
以 Tree View 为配置，提供左侧搜索与树、右侧当前节点内容及节点操作的标准页面；既能从导航打开，也能作为组合中的页面内容。
_Avoid_: 组织专属树页面、仅有树控件

**通用标签页页面（Standard Tab Page）**：
以 Tab View 为配置，按标签装载页面并协调选择与生命周期的标准页面；其标签内容不限于使用 View 配置的标准页面。
_Avoid_: Tree View 私有标签、只能承载 View 的容器

**Tree View（树视图）**：
供通用树管理页面使用、声明树能力、节点类型、节点对应页面与节点菜单的视图配置；它不定义组织层级或其他模块的业务规则。
_Avoid_: 组织模型、部门层级、通用树存储

**Tab View（标签页视图）**：
供通用标签页页面使用、独立声明有序标签及各标签 PageRef 的视图配置；被引用页面可以接收另一个 View 作为参数，也可以是不需要 View 的自定义页面。
_Avoid_: Tree View 私有标签、Link、已打开对象列表

**标签页组（Tab Group）**：
由同一 Tab View 定义的标签集合，包含各标签的身份、标题、顺序和默认选择；切换内容上下文不产生新的对象文档标签。
_Avoid_: 动态窗口集合、浏览历史

**节点上下文（Node Context）**：
树选择传递给页面或操作的节点身份及相关业务事实；其业务含义由模块解释，节点身份不自动等于业务对象主键。
_Avoid_: 全局筛选、宿主组织字段、隐式路由参数

**页面输入契约（Page Input Contract）**：
被引用页面对所需参数与上下文的显式声明；缺少必需输入表示该页面无法成立，不表示可以切换为另一个无上下文的内容。
_Avoid_: 默认全局查询、页面私有参数猜测

**页面实例（Page Instance）**：
一个页面在特定组合位置、参数与上下文中的呈现身份；复用同一页面或视图配置不意味着共享筛选、分页或选择状态。
_Avoid_: View 定义、全局页面状态
