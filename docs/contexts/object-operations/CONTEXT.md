# Object Operations

对象操作上下文定义正式业务写入共用的操作入口，以及由对象拥有者声明、可由任意组件提供实现的横切扩展。统一入口、轻量行为基类、启动期扩展拓扑、嵌套协调、事务内有效视图和可信审计作用域已经落地；当前完整采用范围仅为 Organization 的写操作，其他模块尚未迁移。

Organization 当前声明公司、部门、岗位和人员的创建、普通更新、条件删除，以及人员 `enable`、`disable`、`bind-user` 专用动作。现有 HTTP 与服务端入口都适配到这些动作；直接公共对象入口从可信审计作用域取得主体，旧服务 actor 参数保持原协议且必须与可信主体一致。人员旧服务仅将既有协议适配到统一执行器，人员行为组合独立的生命周期与永久绑定核心，不回调旧服务。旧服务延迟解析必需的执行器，使扩展仍可依赖旧服务执行嵌套动作；内部核心不依赖旧服务或对象执行器。人员专用直接 DML 在同一事务内同步数据库实际值、EF tracked 状态、行为结果和缓存变更登记，避免后续普通写入覆盖专用动作事实。

对象行为基类直接组合公共默认写入模块，由其执行创建、更新、删除的字段规则、可信审计赋值、持久化与记录登记。创建和更新共用字段规则实现，各自保留动作顺序与完整候选语义。Standard CRUD 服务负责读取、统一入口路由和写后展示；未接入对象行为的资源复用同一默认写入模块，事务与缓存提交仍由现有平台执行器拥有。

## Language

**对象操作（Object Operation）**：
针对对象执行的具有明确业务含义的写入，包括创建、修改、删除及停用、绑定等专用操作。正式业务写入通过统一对象操作入口执行适用规则，不因调用来源不同而绕过规则。
_Avoid_: 任意数据库写入、把所有业务动作统称为保存

**对象拥有者（Object Owner）**：
拥有对象业务含义和规则的模块，并决定对象的哪些操作允许横切扩展。
_Avoid_: 横切实现提供者、持久化执行器

**对象行为（Object Behavior）**：
对象拥有者集中表达该对象支持的操作、横切开放范围及专用实现归属的行为定义，在对应操作中完成必需规则与实际处理。普通写入可复用包含审计字段赋值的公共默认行为。
_Avoid_: 持久化实体、包含全部逻辑的大基类

**对象操作扩展点（Object Operation Extension Point）**：
对象拥有者针对整个对象操作显式开放的横切契约，不由对象逐阶段单独授权。其他组件提供扩展实现，不自行增加该对象的可扩展操作。
_Avoid_: 任意方法拦截、组件自行开放他人对象动作

**对象操作扩展（Object Operation Extension）**：
由任意组件提供、接入对象拥有者已声明扩展点的横切实现。实现提供者与对象拥有者可以是不同组件；扩展补充校验或处理，不替换对象的核心行为。
_Avoid_: 对象核心行为、未声明的方法拦截

**操作前扩展（Before-operation Extension）**：
在同一事务中、核心操作执行前运行的对象操作扩展，可通过受控上下文补充业务输入或拒绝操作；最终输入仍须满足对象必需规则。
_Avoid_: 事务外任意预处理、绕过对象校验

**操作后扩展（After-operation Extension）**：
在同一事务中、核心操作完成后且数据库提交前运行的对象操作扩展；失败使整次操作回滚。
_Avoid_: 提交成功通知、提交后外部副作用

**嵌套对象操作（Nested Object Operation）**：
在一个对象操作内，通过目标对象正式入口调用的另一个操作，共享外层事务并执行目标自身的规则和横切。
_Avoid_: 直接跨模块写库、独立提交的子事务

**事务内有效视图（Transaction-effective View）**：
同一事务内供对象操作规则读取的当前事实，包含该事务前序已完成操作的新增、修改和删除。它不向事务外读者公开尚未提交的变化。
_Avoid_: 提前发布的公共缓存、固定的提交前快照
